# QMIX + Simple Spread

Командный проект по Reinforcement Learning: обучение кооперативных агентов алгоритмом QMIX в среде Simple Spread.

## Цель

Показать, как QMIX обучает агентов с общей наградой и как после обучения каждый агент выбирает действие по своему локальному наблюдению. Итоговые материалы: Google Colab с обучением и числовым примером TD-обновления, график результатов, демонстрация обученных агентов, презентация и видео на 5–7 минут.

## План и участники

## Структура репозитория

| Папка | Назначение |
| --- | --- |
| `notebooks/` | Colab: проверка среды, обучение QMIX, оценка модели |
| `src/` | Исходный код алгоритма и вспомогательных компонентов |
| `configs/` | Зафиксированные параметры среды, обучения и оценки |
| `models/` | Сохранённые обученные модели |
| `results/` | Таблицы метрик и графики экспериментов |
| `presentation/proposal/` | Предварительная презентация |
| `presentation/final/` | Финальная презентация |
| `media/demo/` | Короткие демонстрации работы агентов |
| `media/video/` | Видео защиты на 5–7 минут |

Имена и форматы итоговых файлов команда фиксирует при первом рабочем запуске. В презентацию и видео добавляются только результаты из сохранённых запусков.
