**B. Правильность QMIX (по статье Rashid et al., 2018)**

- B1. Сеть агента одна на всех (общие веса). На вход получает своё наблюдение, своё прошлое действие и номер агента, внутри рекуррентный слой GRU, на выходе 5 чисел — по одному на действие. Так в статье.
- B2. Смешивающая сеть получает 2 выбранные оценки агентов и полное состояние. Её веса порождают гиперсети из полного состояния, веса берутся по модулю (неотрицательные), скрытый слой 32 нейрона с ELU, последний сдвиг — двухслойная сеть от состояния. Так в статье.
- B3. Монотонность проверена числом: производная общей оценки по оценке каждого агента не отрицательна на 1000 случайных входах; и лучшее совместное действие из всех 5 × 5 = 25 вариантов совпадает с тем, что каждый агент выбирает сам. Это главное свойство QMIX, на нём держится децентрализованное выполнение.
- B4. TD-цель считается целевыми (замороженными) копиями сетей, которые обновляются раз в 200 эпизодов, γ = 0.99. Конец эпизода по лимиту 25 шагов не считается «настоящим концом»: оценку следующего состояния не обнуляем, потому что агент не видит номер шага (обоснование — Pardo et al., 2018).
- B5. При выполнении политики используются только сети агентов и их собственные наблюдения. Смешивающая сеть и полное состояние нужны только при обучении. Это видно по коду функции выбора действий.
- B6. Все отличия от статьи перечислены в разделе «Ограничения и отличия».

### 6.1. Основная модель (seed 0)

### 6.3. Как пришли к итоговым настройкам

Сначала всё было сделано точно как в статье: γ = 0.99, в TD-цели обычный максимум по целевой сети. На этих настройках обучение работало плохо. Что нашли (все числа — в `results/tables/qmix_pilot_runs.csv`):

1. **Как в статье.** Seed 0 научился (−27.7 к 90 000 шагов), а потом развалился до −96.9, и ошибка выросла до 726. Seed 1 и 2 вообще не научились (около −95).
2. **Почему не учились.** У застрявшего seed 1 жадные действия были перекошены: «вниз» в 59 % случаев, «вправо» почти никогда. Только 41 % движений вели к ближайшей точке, то есть хуже подбрасывания монеты. Агенты уезжали в одну сторону далеко за пределы квадрата, в котором стартуют (до расстояния 4–5 от центра).
3. **Почему разваливалось.** У Simple Spread нет стен, а гиперсети смешивающей сети линейны по состоянию. Для далёких состояний они выдают огромные веса смешивания. Замер на разошедшемся запуске: сеть оценивала далёкие состояния как +619, а близкие как +185. Настоящие значения отрицательные, и далеко они хуже. Получался замкнутый круг: сеть считает «уехать» выгодным → агенты уезжают → данных из далёких состояний больше → оценки там растут дальше.
4. **Что не помогло:** более долгое исследование (200 000 шагов вместо 50 000), более частое обновление целевой сети (раз в 50 эпизодов — ошибка до 3.8 млн), шаг обучения 0.001.
5. **Что помогло:**
   - **Double Q-learning** (так сделано в эталонном коде авторов QMIX, pymarl): развал наступает позже, но не исчезает;
   - **мягкий ограничитель состояния** перед гиперсетями, $3 \cdot \tanh(s/3)$: после него учатся все проверенные seed, включая 1 и 3, которые раньше не учились;
   - **γ = 0.95 вместо 0.99**: с ограничителем, но при γ = 0.99 средняя Q_tot всё равно медленно уходила в плюс (+68.8 у seed 1 к 250 000 шагов, хотя все награды отрицательные). При γ = 0.95 она держится около −10…−12, как и должно быть.

Итоговые настройки (γ = 0.95, Double Q, ограничитель) на пробных seed 1 и 3 дали −26.4 и −26.2 в лучшей точке и −30.0 и −27.7 к 250 000 шагов.

### 6.4. Числовой пример TD-обновления

Это готовая таблица для слайда. Смешивающая сеть в примере однослойная, $Q_{tot} = w_1 Q_1 + w_2 Q_2 + b$, чтобы всё считалось руками. В настоящей сети есть скрытый слой, а веса зависят от состояния, но TD-шаг устроен так же. Все числа пересчитаны через автоматическое дифференцирование PyTorch, расхождение 0.

| Шаг | Формула | Значение |
| --- | --- | --- |
| Дано: награда за шаг r | | −1 |
| Дано: коэффициент дисконтирования γ | | 0.95 |
| Дано: оценки агентов для выбранных действий Q₁, Q₂ | | −4, −6 |
| Дано: веса смешивания для текущего состояния w₁, w₂, b | | 0.5, 1.0, −2 |
| 1. Текущая общая оценка Q_tot | w₁·Q₁ + w₂·Q₂ + b | −10 |
| 2. Лучшая оценка агента 1 в следующем шаге | max(−6, −5.5, −5, −7, −6.5) | −5 |
| 2. Лучшая оценка агента 2 в следующем шаге | max(−3, −2.5, −4, −3.5, −2.8) | −2.5 |
| 2. Следующая общая оценка Q_tot′ (веса следующего состояния 0.8, 0.4, −3) | w₁′·maxQ₁′ + w₂′·maxQ₂′ + b′ | −8 |
| 3. TD-цель y | r + γ·Q_tot′ = −1 + 0.95·(−8) | −8.6 |
| 3. TD-ошибка δ | y − Q_tot | 1.4 |
| 3. Ошибка, которую минимизируем | δ² | 1.96 |
| 4. Градиент по Q_tot | −2·δ | −2.8 |
| 4. Сигнал агенту 1 / агенту 2 | −2·δ·w₁ / −2·δ·w₂ | −1.4 / −2.8 |
| 4. Градиенты по w₁, w₂, b | −2·δ·Q₁, −2·δ·Q₂, −2·δ | 11.2, 16.8, −2.8 |
| 5. Шаг 0.005: новые w₁, w₂, b | параметр − шаг·градиент | 0.444, 0.916, −1.986 |
| 5. Новая общая оценка Q_tot | | −9.258 |
| 5. Новая TD-ошибка | y − новая Q_tot | 0.658 (было 1.4) |

Смысл: сеть ожидала −10, а вышло лучше (−8.6), поэтому Q_tot поднимается. Агент 2 получает вдвое больший сигнал, потому что его вес смешивания вдвое больше. Так смешивающая сеть делит «заслугу» за общую награду между агентами.

Тот же расчёт на настоящем шаге обученной модели — в разделе 11 notebook. Там шаг 5 эпизода с seed 30 000: Q_tot = −3.868, TD-цель −4.459, ошибка −0.591. После одного шага градиентного спуска (размер 0.0001) Q_tot = −3.987, ошибка −0.471.

## 8. Ограничения и отличия от статьи

1. **γ = 0.95 вместо 0.99.** При 0.99 оценки уходили в положительную область, хотя все награды отрицательные, и обучение разваливалось (6.3). Эпизод длится 25 шагов, горизонта около 20 шагов для этой задачи достаточно.
2. **Double Q-learning в TD-цели.** В статье написана обычная DQN-цель с максимумом по целевой сети. В эталонном коде авторов (pymarl) для QMIX по умолчанию включён Double Q. Мы делаем так же.
3. **Ограничитель состояния 3·tanh(s/3) перед гиперсетями.** Этого в статье нет. В SMAC, на котором проверяли статью, признаки состояния ограничены, а в Simple Spread координаты не ограничены ничем. Без ограничителя часть seed не училась вообще.
4. **Короткое обучение.** 200 000 шагов (5 минут) против миллионов шагов в статье. Этого хватает, чтобы выйти на плато для 2 агентов, но не больше.
5. **Зависимость от seed.** Из трёх итоговых запусков один (seed 1) заметно слабее и к концу обучения немного деградирует. Мы этого не скрываем; основная модель — seed 0.
6. **Поведение после 25 шагов не обучалось.** Основная модель держит позиции и на 150 шагах, а модель seed 1 — нет. Если показывать длинные эпизоды, брать seed 0.
7. **Штраф за столкновения не учитывается.** При `local_ratio=0` его нет в награде (так требует задание). Поэтому агенты могут проходить вплотную друг к другу, и это не ошибка обучения.
8. **Проверка в настоящем Colab** у агента невозможна. Проверено в чистом окружении с теми же командами; один прогон в Colab должен сделать Карим.
